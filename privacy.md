# Privacy Policy for von

_Last updated: 23 August 2026_

## Summary

**von** is a private application used by one person: its owner and operator.
It has no other users. No data is sold, shared, transferred, or disclosed to
any third party.

## What data is accessed

With the owner's explicit Google OAuth consent, von accesses:

- **Gmail (read-only)** — message metadata and content, to summarise and search
- **Google Calendar (read-only)** — events, to answer scheduling questions

von holds **read-only** scopes. It cannot send, alter, or delete email; it
cannot create or modify calendar events; and it has no access to Drive, Docs,
Sheets, or Contacts.

## How data is used

Data is used only to answer the owner's own questions about their own account.
It is not used for advertising, profiling, model training, resale, or analytics.

## Storage and retention

von runs on a private server controlled by the owner. OAuth tokens are stored
on that server with restricted file permissions and are never transmitted
elsewhere. Message content is processed transiently to produce answers and is
not retained in a separate database. The owner may revoke access at any time
via https://myaccount.google.com/permissions, which immediately and
permanently ends all access.

## Sharing

None. No data is shared with any third party, service, or person other than
the owner.

## Limited Use disclosure

von's use and transfer of information received from Google APIs adheres to the
[Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy),
including the Limited Use requirements.

## Contact

Questions about this policy should be directed to the repository owner via
GitHub.
